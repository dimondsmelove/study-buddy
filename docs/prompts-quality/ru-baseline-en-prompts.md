## Explain — code with a bug — preset: explain
_latency:_ 14959ms

В одной фразе: этот код пытается сложить элементы массива [1, 2, 3], но из-за ошибки «на единицу» в условии цикла (i <= nums.length) он выходит за границы массива и получает NaN, а не ожидаемую 6; при этом переменная sum изначально инициализируется нулём.

Пошагово:



Создаётся массив nums = [1, 2, 3] (индексы элементов: 0, 1, 2).
Переменная sum объявляется со значением 0.
Запускается цикл for:
i = 0: sum += nums[0] → sum = 0 + 1 = 1
i = 1: sum += nums[1] → sum = 1 + 2 = 3
i = 2: sum += nums[2] → sum = 3 + 3 = 6
i = 3: условие i <= nums.length (3 <= 3) всё ещё истинно, поэтому цикл выполняется снова.


На шаге i = 3 происходит обращение к nums[3], которого не существует (в массиве только 3 элемента, индексы 0–2). В JavaScript это даёт undefined.
sum += undefined превращает число в NaN (Not a Number).
console.log(sum) выведет NaN, а не 6.


Ключевые термины:


Массив (Array): упорядоченный набор элементов, доступ к которым идёт по индексу, начиная с 0.
length: свойство, возвращающее количество элементов в массиве (в данном случае 3).
Ошибка «на единицу» (Off-by-one error): ошибка в условии цикла, когда он выполняется на один раз больше или меньше, чем нужно. Правильное условие для данного случая: i < nums.length.
undefined: значение, которое возвращается при обращении к несуществующему индексу массива.
NaN (Not a Number): результат математической операции, в которой участвует не число (например, undefined).

## Summarize — article — preset: summarize

Ревайлдинг — форма экологического восстановления, цель которой вернуть земле более дикое состояние.
В отличие от традиционной охраны (которая «замораживает» экосистему в выбранной точке), ревайлдинг позволяет естественным процессам формировать её.
Ключевой вид (например, волк в Йеллоустоуне) может запустить каскад изменений, затрагивающий реки, леса и даже русла ручьёв.
Критики отмечают, что такой подход непредсказуем и его трудно измерить.
Сторонники возражают: непредсказуемость и есть главная суть метода.

## Explain — code with a bug — preset: explain
_latency:_ 20496ms

Суть: Цикл выполняется на один раз больше, чем нужно, из-за условия i <= nums.length, и на последней итерации пытается прибавить несуществующий элемент, из-за чего сумма превращается в NaN.
По шагам:

Массив nums = [1, 2, 3] имеет длину 3, а его элементы находятся по индексам 0, 1, 2.
Изначально sum = 0.
Цикл for с условием i <= nums.length (то есть i <= 3) выполняется для i = 0, 1, 2, 3.
Что происходит на каждой итерации:
i = 0: sum += nums[0] → sum = 0 + 1 = 1
i = 1: sum += nums[1] → sum = 1 + 2 = 3
i = 2: sum += nums[2] → sum = 3 + 3 = 6
i = 3: sum += nums[3]. Элемента с индексом 3 не существует, поэтому nums[3] равен undefined. При сложении с числом undefined превращается в NaN (Not a Number). Итог: sum = 6 + undefined = NaN.


Поэтому console.log(sum) выведет NaN, а не ожидаемое 6.

Ключевые термины:

Индекс: позиция элемента в массиве. Отсчёт начинается с 0.
Длина массива (length): количество элементов. Для [1, 2, 3] это 3, а индексы — 0, 1, 2.
undefined: значение, которое получается при обращении к несуществующему элементу массива.
NaN: специальное значение «не число», результат некорректной математической операции.

Как исправить: заменить условие на i < nums.length. Тогда последняя итерация будет при i = 2, и сумма корректно станет равной 6.
